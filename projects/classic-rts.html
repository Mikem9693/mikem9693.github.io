The Project

Red Alert is a game I remember fondly from my childhood, knowing that EA had released it as freeware in 2008 made it an ideal choice for a learning project.

Browser games are a popular topic at the moment, and several decompiled games rebuilt to run in the browser have gained large followings. I found two sites that already offered Red Alert. The first used DOS emulation. Even though my laptop is effectively a supercomputer next to the PCs the game was released on, the game stuttered so badly it was close to unplayable. The second site ran the game in the browser, but switching away from it at any point froze the whole tab.

Because EA had released the game’s source code, it could be compiled directly for the web. By testing the second site one variable at a time, I traced the frozen tab to the way the original code was written. It assumes it controls the whole machine and waits inside its own loops, never handing control back to the browser. That gave me the clearest test of whether my project was viable. Switching tabs, resizing the window or opening developer tools must not freeze the game, and that became one of my acceptance tests.

My role

I ran this as product owner and delivery lead, with an AI coding assistant (Claude Code) as the engineer. I split the work into phases with clear gates. Each ticket had a goal, files in scope, constraints and acceptance tests. I reviewed every plan before approving it and every diff before committing it. If there was something I didn’t understand, I researched or asked a separate AI chat to explain remaining true to the goal of learning not just letting AI develop. I decided what was in or out of scope. Licensing, security, privacy, hosting and release timing were my decisions, and I recorded the reasoning for each.

I managed the release myself, setting up hosting accounts, uploading game data and deploying each version with tagging in Git. Every version links to its exact source code.

I learned the technical side alongside delivery; Linux toolchain, Git, C++ build systems WebAssembly and the basics of cloud hosting and web security.
